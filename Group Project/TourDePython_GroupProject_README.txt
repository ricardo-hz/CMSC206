Due to the large amount of data our group processed and memory limitations imposed by Google, our project cannot be run in the free version of Google Colab. Instructions on how to run our project can be found below.
- Google Colab (PAID)
  - Load notebook
  - Select "Runtime" in top menubar
  - Select "Run All"
- VSCode, Jupyter Notebook, and most other interpretors
  - Load notebook
  - Locate the "Run All" button in your interpreter
  - Select "Run All"
